============================================
  MajestyLauncher - Installation Windows
============================================

Contenu du ZIP :
  - MajestyLauncher.bat  (installateur)
  - bootstrap.jar        (bootstrap du launcher)
  - MajestyCraft.ico     (icone du launcher)

Installation :
  1. Extraire le ZIP dans un dossier de votre choix
  2. Double-cliquer sur MajestyLauncher.bat
  3. Suivre les instructions a l'ecran
  4. L'installateur va :
     - Telecharger Java 8 automatiquement
     - Installer le bootstrap
     - Creer un raccourci sur le bureau
     - Lancer MajestyLauncher

Desinstallation :
  - Relancer MajestyLauncher.bat et choisir "Desinstaller"

Configuration requise :
  - Windows 10 ou superieur
  - Connexion internet (pour le telechargement de Java)
  - ~200 Mo d'espace disque
